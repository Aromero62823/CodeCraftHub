# CodeCraftHub

## Project Overview
CodeCraftHub is a simple, personalized learning platform designed for developers to track and manage their courses. Built using Python and the Flask framework, this RESTful API allows users to add, retrieve, update, and delete course information stored in a JSON file.

## Features
- **Manage Courses**: CRUD operations (Create, Read, Update, Delete) for course management.
- **Simple Data Storage**: All course data is stored in a JSON file, eliminating the need for a complex database setup.
- **No User Authentication Required**: Focus solely on course management without user login.
- **RESTful API**: Learn the basics of RESTful practices and HTTP methods.
- **Easy-to-Use Endpoints**: Simple and intuitive API endpoints for beginners.
